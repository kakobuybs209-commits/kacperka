Test: openImageLightbox() Function

Test Scenario

This test verifies that the openImageLightbox() function:

  1. Gets the lightbox element (pdv-lightbox)
  2. Gets the lightbox image element (pdv-lightbox-image)
  3. Sets the image src to the provided imageSrc parameter
  4. Removes 'hidden' class from lightbox
  5. Sets document.body.style.overflow = 'hidden' to prevent scroll
